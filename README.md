# WORD FLOW Ver.2

외우려고 하는 것이 아니라, 계속 만나게 하는 영어 단어 노출 웹 앱입니다.
HTML · CSS · Vanilla JavaScript만 사용하며, 백엔드/데이터베이스/로그인/영구 저장이 없습니다.
(진행 기록은 페이지 메모리에만 있고, 새로고침하면 새 세션으로 시작합니다.)

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 홈 · 퀴즈 · 결과 화면 마크업 |
| `style.css` | 디자인(반응형, 다크 모드, 모션 최소화 대응) |
| `engine.js` | 데이터 해석 · 문제/보기 생성 · 세션 통계 · 스톱워치 (화면과 무관한 로직) |
| `script.js` | 화면 전환, 이벤트, 결과 카드 렌더링 |
| `data/` | 단어 데이터셋 폴더. 안에 `이름.json` 파일을 여러 개 둘 수 있음 |
| `data/manifest.json` | 데이터셋 파일명 목록 (**파일을 추가/삭제하면 여기도 수정**) |

> 현재 `data/sample.json`은 동작 확인용 샘플 43개입니다. 본인의 데이터 파일을 `data/`에 넣고 `manifest.json`에 파일명을 적으세요.

## 데이터셋 추가하는 법

1. `data/` 폴더에 `원하는이름.json`을 넣습니다. (이름은 자유, 한글·공백 가능)
2. `data/manifest.json`에 파일명을 적습니다.

   ```json
   ["sample.json", "원하는이름.json", "토익 단어.json"]
   ```

3. 첫 화면 드롭다운에 **확장자를 뺀 이름**(`sample`, `원하는이름`, `토익 단어`)으로 표시되며, 적은 순서대로 나옵니다.

정적 호스팅은 폴더 안 파일 목록을 읽을 방법이 없어서 `manifest.json`이 필요합니다.
로컬 `python -m http.server`처럼 폴더 목록을 보여주는 서버에서는 `manifest.json`이 없을 때 `.json` 파일을 자동으로 찾지만, 배포 환경에서는 동작하지 않을 수 있으니 `manifest.json`을 유지하세요.

## 출제 방향 (영→한 / 한→영)

첫 화면의 토글 스위치로 고릅니다. (기본: 영→한)

- **영→한**: 영어 단어를 보고 한국어 뜻 5개 중에서 고릅니다.
- **한→영**: 한국어 뜻을 보고 영어 단어 5개 중에서 고릅니다. 한 단어에 뜻이 여러 개면 **모두** 화면에 표시합니다.

## 데이터 파일 형식

단어 객체의 배열입니다. (`{ "words": [ ... ] }`처럼 배열 하나를 담은 객체도 읽습니다.)

```json
{
  "word": "abundant",
  "pos": "adjective",
  "pronunciation": "/əˈbʌndənt/",
  "meaning": "풍부한",
  "example": "There is abundant evidence to support it.",
  "example_translation": "그것을 뒷받침하는 풍부한 증거가 있다.",
  "level": "B2",
  "group": "12"
}
```

- `pos`, `meaning`은 문자열이어도, 문자열 배열이어도 됩니다. 원본 값은 수정하지 않습니다.
- `level`, `group`은 숫자여도 됩니다.
- 비어 있는 값은 결과 카드에 `—`로 표시됩니다.

### 출제 규칙 (배열 데이터 포함)

- 문제 단어는 매번 전체에서 독립적으로 균등 랜덤 선택합니다.
- 오답 후보는 정답과 **품사 항목을 하나라도 공유**하는 다른 단어입니다. (두 방향 공통)
- 영→한에서 뜻이 여러 개면 보기 하나에는 뜻 하나만 사용합니다.
- 정답 단어의 어떤 뜻과도 겹치는 후보는 제외하고, 보기 문구가 서로 같지 않도록 합니다.
- 5개 보기를 만들 수 없는 단어는 다른 품사로 채우지 않고 그 문제를 건너뜁니다.
- `word`가 없는 항목은 무시하고, `pos`/`meaning`이 없는 단어는 출제 대상에서만 빠집니다.

## 로컬에서 실행

`file://`로 `index.html`을 직접 열면 브라우저가 `fetch()`를 막습니다. 폴더에서 정적 서버를 실행하세요.

```bash
python -m http.server 8000
# 또는
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

## 배포 (무료 정적 호스팅)

이 폴더 전체(`index.html`, `style.css`, `engine.js`, `script.js`, `data/`)를 그대로 올리면 됩니다. 빌드 과정은 없습니다.

- **GitHub Pages**: 저장소에 파일 업로드 → Settings → Pages → Branch 선택 → `https://<계정>.github.io/<저장소>/`
- **Netlify**: 폴더를 Netlify Drop(app.netlify.com/drop)에 끌어다 놓기
- **Cloudflare Pages / Vercel**: 프로젝트 생성 후 이 폴더를 정적 사이트로 배포 (빌드 명령 없음, 출력 디렉터리 `/`)

`data/`는 상대 경로로 읽으므로 하위 경로(`/<저장소>/`)에 배포해도 동작합니다.

## 데이터 로딩 오류가 날 때

1. `data/` 폴더가 `index.html`과 **같은 위치**에 있는지, `manifest.json`의 파일명이 실제 파일명과 정확히 같은지 확인(대소문자 포함)
2. 로컬이라면 `file://`가 아니라 서버(`http://localhost`)로 열었는지 확인
3. JSON 문법 오류(쉼표, 따옴표)가 없는지 확인 — 오류 메시지에 어느 데이터셋인지와 위치가 표시됩니다
4. 파일이 UTF-8인지 확인
5. 배포 후 수정했는데 그대로라면 브라우저 캐시를 새로고침(Ctrl+Shift+R)

## 사용 팁

- 키보드 `1`~`5` 키로도 보기를 선택할 수 있습니다.
- 정답이면 약 0.8초, 오답이면 정답을 읽을 수 있도록 약 1.8초 뒤 다음 문제로 넘어갑니다. (`script.js` 상단의 `DELAY_*` 값으로 조절)
